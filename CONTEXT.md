# Rehost WebForms

Rehost WebForms preserves the portable managed behavior of classic ASP.NET Web
Forms applications independently of IIS hosting.

## Language

**Managed Web Forms runtime**:
The supported portable application runtime, spanning application startup,
managed request processing, dynamic compilation, and request completion.
_Avoid_: core, System.Web core

**Classic managed pipeline**:
The initial supported request-processing contract, with the managed runtime
owning the complete request lifecycle rather than responding to IIS-native
notifications.
_Avoid_: temporary pipeline

**IIS-integrated pipeline**:
The IIS-owned compatibility profile driven by native notifications and native
module inventory. It is outside the initial managed Web Forms runtime contract.
_Avoid_: default pipeline

**Semantic oracle**:
The authoritative executable reference used to determine observable legacy
behavior when expected behavior is uncertain. For the classic managed pipeline,
this is .NET Framework 4.8.1 driven through its managed request entry.
_Avoid_: documentation alone, Reference Source alone

**Core differential probe**:
One fixture executed through equivalent recording `HttpWorkerRequest`
boundaries on the .NET Framework oracle and portable runtime, comparing managed
pipeline observations independently of IIS or Kestrel transport.
_Avoid_: end-to-end host test

**Adapter integration probe**:
A Kestrel-hosted test of request translation, completion, disconnect, and host
lifecycle behavior. It does not establish internal System.Web semantics.
_Avoid_: semantic oracle

**Normalization manifest**:
The checked-in, narrowly justified list of inherently host-specific values
removed or canonicalized before differential comparison.
_Avoid_: snapshot scrubber, ignore list

**Oracle trace**:
A provenance-stamped observation generated by the checked-in harness on pinned
.NET Framework 4.8.1. Portable tests consume it; humans do not author it.
_Avoid_: expected-output fixture

**Application runtime**:
The process-scoped lifecycle owner for one configured Web Forms application,
from validation and startup through request admission and shutdown. It publishes
no usable application state until required startup succeeds.
_Avoid_: bootstrap, HostingEnvironment

**Accepting requests**:
The application-runtime state reached after request-independent startup. It
permits dispatch but does not imply that lazy first-request initialization has
completed.
_Avoid_: ready

**Stop requested**:
The terminal-admission state: the current managed request may complete, new
requests are rejected, and the owner has been notified to stop the generation.
_Avoid_: faulted, restarted

**First-request initialization**:
The once-only, request-dependent transition performed using the first real
request before normal application dispatch.
_Avoid_: eager pipeline initialization, warm-up

**Application activation**:
The once-only transition that creates an application runtime from validated
host configuration. By default, the first routed request triggers activation
and waits outside System.Web until the application can accept requests.
_Avoid_: first-request initialization

**Host registration**:
The mutation-free creation of an application runtime from explicit host
options. It establishes intent but does not activate System.Web or publish
legacy global state.
_Avoid_: initialization, activation

**Host-contract validation**:
Validation of host-owned identity, roots, baseline assets, writable work
storage, and ownership conflicts before legacy global mutation. It does not
open or evaluate application System.Web configuration.
_Avoid_: configuration preflight

**Compatibility envelope**:
The explicitly supported set of Web Forms behaviors within which observed
.NET Framework semantics are preserved. Behavior outside it is either a
documented deviation or explicitly unsupported.
_Avoid_: best effort, mostly compatible

**Legacy hosting adapter**:
Internal machinery retained to preserve useful Framework hosting sequencing and
compatibility surfaces while delegating process lifecycle ownership to the
application runtime.
_Avoid_: lifecycle owner, host interface

**Registered lifecycle bridge**:
The internal portable `IRegisteredObject` created through `ApplicationManager`.
It preserves hosting registration and relays `Stop`; it does not process
requests or own application policy.
_Avoid_: runtime, request handler

**Surgical port**:
A portability change that preserves the Framework managed sequence and replaces
or disables only the incompatible leaf mechanism proven to block it.
_Avoid_: clean rewrite, blanket platform fork

**Disabled subsystem**:
A subsystem placed into an authoritative inactive mode while retaining every
initialized object and state postcondition expected by its consumers.
_Avoid_: skipped initialization, silent no-op

**Portability ledger**:
The evidence record for the supported classic path, mapping each legacy call to
its required postconditions, platform dependency, chosen treatment, and
behavioral proof.
_Avoid_: dependency encyclopedia, porting checklist

**Host adapter**:
The host-specific translator that selects requests, creates host-neutral request
inputs, awaits completion, and relays lifecycle signals. It triggers but does
not own application activation or System.Web lifecycle.
_Avoid_: application runtime, pipeline owner

**First-slice transport envelope**:
The deliberately small Kestrel translation contract for bodyless requests,
empty path info, standard metadata, memory responses, status, headers, and
final completion.
_Avoid_: general HTTP compatibility

**Response spool**:
The per-request memory-then-work-file sink that records logical System.Web
response operations and is asynchronously committed to Kestrel after managed
completion.
_Avoid_: response buffer, synchronous Kestrel response

**Request-body bridge**:
The later transport component that adapts asynchronous Kestrel body production
to System.Web synchronous and asynchronous entity-body reads.
_Avoid_: eager full-body buffering, AllowSynchronousIO

**Managed request failure**:
An application, module, or handler failure owned and formatted by System.Web
before normal request completion.
_Avoid_: adapter failure

**Activation escape**:
An exception that leaves application activation after legacy global mutation
has begun, before System.Web can own it as a request failure. It terminates the
generation and requests host shutdown.
_Avoid_: initialization error, managed request failure

**Adapter failure**:
A host-translation or transport failure that prevents System.Web from completing
the request normally and therefore faults host-side completion.
_Avoid_: managed request failure

**Request disconnect**:
The host signal that the client connection is gone. It is observable by the
managed pipeline but is not itself an instruction to terminate that pipeline.
_Avoid_: cancellation

**Application generation**:
The immutable configuration, binaries, pages, resources, and generated state
served by one application process. A deployment change creates a new generation
in a replacement process.
_Avoid_: live deployment, partial reload

**Terminal shutdown notification**:
The one-shot signal from the managed runtime to its owning host that the current
application generation cannot continue. It requests host shutdown; it does not
restart or terminate the process itself.
_Avoid_: AppDomain restart, process restart

**Application work root**:
The explicit writable root owned by one application generation for generated
code, caches, and other disposable runtime state.
_Avoid_: source root, assembly location, ambient temporary directory

**Application-bin resolver**:
The process-owned immutable managed-assembly resolver for the explicit
application `bin` directory, replacing AppDomain private-bin probing.
_Avoid_: host project reference, current-directory probing

**Portable configuration baseline**:
The host-supplied root configuration defaults required for deterministic,
cross-platform operation. Normal configuration parsing and inheritance apply
above it; unsupported effective settings fail activation.
_Avoid_: rewritten application configuration, hidden override

**Framework-derived root baseline**:
The portable root `web.config` whose structure and defaults trace to the pinned
.NET Framework 4.8.1 root configuration. Every portability adaptation is
explicitly inventoried.
_Avoid_: minimal invented baseline

**Precompiled handler slice**:
The first executable request slice: normal classic-pipeline handler mapping
selects a handler type already available in an application assembly.
_Avoid_: host-injected handler, direct handler dispatch

**First-slice parity gate**:
The required oracle scenarios that must match before the precompiled-handler
slice is complete, covering cold start, concurrency, async completion,
short-circuiting, failures, and terminal shutdown.
_Avoid_: smoke test

**Dynamic compilation leaf**:
A `BuildManager` operation that compiles application source such as `.aspx`,
`App_Code`, or `Global.asax`. It is narrower than `BuildManager` initialization
and precompiled type resolution.
_Avoid_: BuildManager subsystem
