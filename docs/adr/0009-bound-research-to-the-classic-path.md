# Bound research to the supported classic path

Before implementation, Rehost records a portability ledger from application
activation through `HostingEnvironment`, the `HttpRuntime` phases, first handler
dispatch, and response completion. Each entry identifies required state,
platform dependency, treatment, and observable proof.

The ledger is complete only for behavior needed by the next executable slice
and expands incrementally. A comprehensive IIS/System.Web dependency
encyclopedia is not a prerequisite.
