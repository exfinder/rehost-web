# Classic-path portability ledger

Add an edge when executable application work reaches it; keep unreached work in the
[backlog](backlog.md). Each row records the incompatible leaf and observable treatment; callers
and Framework sequencing stay intact unless stated.

- **keep:** unchanged managed behavior.
- **inactive:** initialized state with no active capability.
- **portable leaf:** replace only the platform operation.
- **unsupported:** fail explicitly when selected.

Focused tests and the full solution run on Windows x64, Linux x64 and macOS arm64. Frozen
Framework/adapter gates cover the managed-pipeline boundary; see
[parity rigs](../tests/parity/README.md).
